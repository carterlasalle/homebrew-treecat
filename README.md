# homebrew-treecat

Personal Homebrew tap: [treecat](https://github.com/carterlasalle/treecat) and [tracelayer](https://github.com/carterlasalle/tracelayer).

```bash
brew install carterlasalle/treecat/treecat
brew install carterlasalle/treecat/tracelayer
```

The tracelayer formula is maintained in the tracelayer repo (`contrib/brew/tracelayer.rb`, bump via `contrib/brew/bump.sh`).
